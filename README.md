  🎀 Joke & Quote Generator

Веб-приложение для генерации случайных шуток и вдохновляющих цитат с использованием внешних API. Проект выполнен в нежном розовом дизайне и создан для учебных целей.

  
  1. Описание проекта:

Joke & Quote Generator — это простой веб-сайт, который позволяет пользователю:
 
получать случайные шутки,

получать случайные цитаты,

видеть данные, загруженные с внешних API в реальном времени.

Проект демонстрирует работу с:

HTML, CSS, JavaScript,
асинхронными запросами (fetch, async/await),
внешними API.

  
  2. Используемые технологии:

HTML5 — структура страницы;

CSS3 — стилизация и дизайн интерфейса;

JavaScript (ES6) — логика приложения;

External APIs — получение данных (шутки и цитаты);

GitHub Pages — публикация проекта в интернете.

  
  3. Используемые API

🔹 API для шуток

Загружает случайные шутки

Используется HTTP-запрос fetch()

🔹 API для цитат

Загружает случайные цитаты и авторов

Используется асинхронный запрос async/await

API используются без ключей доступа (public API).

  
  4. Установка и запуск проекта

Первый вариант: Открыть проект можно с помощью VS кода. Для чего надо сначала через гитхаб скачать проект, а потом его вставить его в VS.

Второй вариант: Также можно и без кода посмотреть проект. В гитхабе есть прямая ссылка на сам проект. Можно открыть его и посмотреть (https://sezim673.github.io/Joke_generator/)
